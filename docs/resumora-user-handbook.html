08 · Owner

Deployment and maintenance

For the project owner; normal resume users do not need this chapter.

A1Deploy frontend on VercelBuild the shared package before Next.js.+
1

Root Directory

Use apps/web and enable outside source files.

2

Use vercel.json

It installs from the root and builds @resumora/domain before web.

3

Public variables only

Set API URL, Supabase URL, and publishable key—never server secrets.

A2Deploy backend on RenderUse the Blueprint or exact monorepo commands.+
1

Build

Leave Root Directory blank. Use npm ci && npm run build -w @resumora/domain && npm run build -w @resumora/api.

2

Start

Use npm run start -w @resumora/api and health path /health.

3

Private environment

Configure Supabase, DeepSeek, R2, WEB_ORIGIN, CRON_SECRET, and RETENTION_DAYS.

A3Maintain free-tier keepalivePing Render and perform bounded upkeep.+
1

Schedule

GET https://resumoraai.onrender.com/internal/cron/keepalive every 13 minutes.

2

Secret header

Use Authorization: Bearer <CRON_SECRET>, never a query string.

3

Interpret

200 means liveness succeeded. Retention runs at most daily.

4

Diagnose 503

Check Render logs, Supabase migrations, R2 permissions, and matching credentials.

09 · Help

Troubleshooting by symptom

Start with what you see, then follow the shortest diagnostic path.

“Private · local”

Finish email sign-in, refresh once, then check Supabase public variables and browser storage.

AI unavailable

Check /health for AI capability, DeepSeek key/model, and Render logs.

Import fails

Use PDF/DOCX/TXT, confirm selectable text, size limits, API, and R2.

Vercel cannot resolve domain

Use apps/web, enable outside sources, and keep vercel.json.

Cron returns 401

Authorization is missing or differs from Render’s CRON_SECRET.

Cron returns 503

Maintenance reached a failing Supabase/R2 step. Check Render logs and integrations.

Portfolio stays private

Sign in, select verified evidence, save, then publish.

Reviewer link invalid

Check email identity, expiration, revocation, and the full token.

PDF layout differs

Use A4, default scale, background graphics, and inspect page breaks.

Owner diagnostic: run npm run check:integrations from the repository root.
